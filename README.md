# Info3_Spiel - Monster Jump

### Ein Studienprojekt von Tobias Hahn, Lutz Morath und Jonas Uzelac


Monster Jump ist ein 2D-Platformer, bei dem zwei Spieler an einer Tastatur oder im Multiplayer gemeinsam spielen. Ziel ist es, kooperativ
einen Ausweg aus dem Level zu finden, indem Rätsel gelöst und Hindernisse überwunden werden.

Spieler 1 bewegt sich mit den Tasten wasd, Spieler 2 mit den Pfeiltasten. 
Um das Level zu beenden müssen beide Spieler auf der Flagge stehen.
Manche Blöcke sind verschiebbar, andere lassen sich mithilfe von Buttons bewegen, Stacheln beenden den Run.

Um den online Multiplayer zu spielen, muss ein Spieler einen Server hosten und der andere Spieler tritt über die lokale IP Adresse des Hosts bei. 

Zur Auswahl stehen 3 lokale Level und eines für den Multiplayer.

Um das Spiel zu starten werden python 3.13 oder älter benötigt, sowie die Pakete pygame und pytmx. Diese können mit folgendem Befehl installiert werden: 

pip install -r requirements.txt
